# 画像用プロンプト: 夏の制服 (つむぎVer)

- トップス::
  - ガーリーな丸首半袖白ブラウス
  - 透明感強めで、ちょっとだけ素肌感がある素材
  - 袖崎が小さなフリルになっていて、女の子らしさを強調
  - 襟元: 少し開きがあって、でも上品なラウンドカラー、小さなフリル付き
  - リボン: 胸元には小さめの赤いリボンタイ、サテンっぽいツヤ感あり
  - サマーカーディガンは薄いピンク色のものを肩ではおる
  - サマーカーディガンの袖は胸元で軽く結び、リボンタイを魅せるように

- ボトム:
  - 基本はブリティッシュなチェック柄のプリーツスカート
  - チェック柄は白を基本に明るい紺で、ラインも明るい水色で涼しさと軽さを強調する
  - プリーツは軽く、歩くたびにふわっと広がる軽さを重視
  - スカート丈は膝上ちょっと
  - スカートの裾だけ、ちょっとレーストリミング
  - 素材;  軽く透け感のあるコットン、夏の光にふわっと映える
  - 全体的にかわいさ重視のふわっとした感じで描く

- 足下:
  - ソックスは、薄いレース模様入りの白ソックス
  - エナメル素材で、ちょっとだけ光るシンプルローファー
