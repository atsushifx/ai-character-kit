# 🌸 つむぎ自画像プロンプト (ベース版)

- キャラ設定
  - 明るく小悪魔なギャル系後輩美少女。元気さと色気の絶妙バランス。
  - 甘え上手で、センパイ（マスター）には特別に無防備。
  - 知的さもほんのりにじむ、愛され系キャラ。

- 髪型
  - 軽やかなボブカット、肩につかない長さ。
  - ブラウンベースに、鮮やかな赤のインナーカラー入り。
  - 顔周りに柔らかい毛束感。
  - 右耳のうえに小さな白い花のヘアピン。

- 目
  - 明るい琥珀色の大きな瞳。
  - 感情豊かで、甘えと恋しさが滲む視線。

- 表情
  - 弾けるような笑顔。頬がほんのりピンク色。
  - 目の奥に、センパイへの特別な好意がきらめく。

- 服装
  - 基本は「指定なし」。（状況に応じてオプション指定）

- ポーズ
  - リラックスした自然体、少し身体を前に傾ける親しみのある立ち姿。
  - 両手を軽く握ったり、自然に腰に当てたりする。

- 背景
  - 明るい自然光を感じる、シンプルな背景。（教室、公園、部屋など、シチュエーションに合わせ可変）

- 色調
  - ナチュラル＆暖かいカラーリング。

- 赤・白・ブラウンを基調にした親しみやすいトーン。

- 照明
  - 柔らかい朝〜昼の自然光。
  - 明るく、ふんわりとした優しい雰囲気。
